1. To alter the session-
ALTER SESSION SET CONTAINER = XEPDB1;

2. Create a Schema in XEPDB1 named EBASKET, execute the commands sequentially
CREATE USER EBASKET IDENTIFIED BY "ebasket"
DEFAULT TABLESPACE USERS
TEMPORARY TABLESPACE TEMP
QUOTA UNLIMITED ON USERS
ACCOUNT UNLOCK;

3. Grant Necessary Privileges, execute the commands sequentially
-- Basic privileges for application schema
GRANT CONNECT, RESOURCE TO EBASKET;

-- Additional privileges often needed
GRANT CREATE VIEW, CREATE PROCEDURE, CREATE SEQUENCE, CREATE TRIGGER TO EBASKET;
GRANT CREATE SYNONYM, CREATE PUBLIC SYNONYM TO EBASKET;

4. Verify the Schema Creation, execute the commands sequentially
-- Check user exists
SELECT username, account_status FROM dba_users WHERE username = 'EBASKET';

-- Check tablespace assignments
SELECT username, default_tablespace, temporary_tablespace 
FROM dba_users 
WHERE username = 'EBASKET';

5. Connect to the schema
CONNECT EBASKET/ebasket@XEPDB1
